# MomentRead

在浏览器里阅读 EPUB，按需请求 AI 解析，在概念分支中深入讨论，再整理并返回原来的阅读思路。

**当前状态：已整理开发架构基线，尚无可执行应用。** 已确定独立本地网页、Claude Code 首个后端及 ThoughtDAG 模块复用方向。本文仍是安装和使用说明草稿；依赖版本、配置路径、安装与启动命令将在实现验证后补齐。

需求与验收见 [PRD](docs/PRD.md)，后续开发从 [技术选型与架构](docs/ARCHITECTURE.md) 开始，已确认的界面见 [设计说明](docs/design/README.md)。

## 使用方式

首版采用本地网页版：用户自行安装依赖、配置 AI 环境，启动本地服务后，通过桌面浏览器使用。不需要公网部署，也不以“别人打开网址即可使用”为首版目标。

界面包括左侧 EPUB、右侧当前 AI 讨论、最右侧概念线路图。一个选段可以展开多个概念讨论，每个讨论又可以继续展开子分支。用户通过“整理并返回”逐层回到直接父讨论。

## 安装前需要准备什么

| 项目 | 当前要求／状态 |
|---|---|
| 电脑与浏览器 | 以 Darren 的 macOS 桌面使用场景为起点；其他平台兼容性待验证 |
| 书籍 | 可选中文字的 EPUB；可以另行补充外文原著 |
| 应用运行依赖 | 建议 React + TypeScript + Vite 前端、Node.js 本地服务；运行时和依赖版本在脚手架验证后固定 |
| AI 运行环境 | 首个后端采用 Claude Code CLI，经本地服务桥接；DSH、OpenCode 保留为后续替代候选，首版不要求全部安装 |
| 模型访问方式 | 按最终后端支持的认证和计费方式配置；已有聊天订阅不自动等于程序化调用可用 |
| 网络 | 使用远程模型和原著检索时需要；本地网页不等于所有 AI 功能离线运行 |

## 快速开始的交付要求

正式 README 将提供下列可复制、已验证的步骤；目前不填入虚构仓库地址、端口或不存在的脚本。

1. 获取项目：实际发布仓库、支持版本，以及需要下载的文件。
2. 安装依赖：准确的运行时版本与安装命令。
3. 配置 AI：支持的后端、认证说明、模型选择及检索配置。
4. 启动：产品和 AI 服务各自的命令，或一个已经实现的统一启动入口。
5. 打开网页：启动输出给出的本地地址，以及正常连接的可观察状态。
6. 导入 EPUB：完成一次选段解析，展开两个同级概念，再从其中一个展开子分支。
7. 整理并返回：确认小结回到直接父讨论，再恢复段落解析。
8. 关闭与接续：正常停止服务，重启后恢复书籍位置及活动讨论。

首次模型连接检查应使用无私人内容的简单请求；确认能够返回后，再处理选定的书籍内容。

## 数据保存与备份

EPUB 引用、阅读位置、讨论关系、确认小结和概念档案由产品在本机保存，与 Claude Code 运行会话分开。当前工程建议为 SQLite 保存结构化记录、文件目录保存书籍和来源材料；数据库绑定、数据目录、文件导入方式和备份操作在持久化开发前定案，详见架构文档。

正式 README 必须说明：

- EPUB 是复制导入还是引用原文件，移动原文件会有什么影响。
- 学习数据与 AI 后端会话分别保存在哪里，如何一起备份和恢复。
- 哪些选段或背景会发给远程模型／检索服务，凭据配置在哪里。
- 更新应用时如何保留数据；需要迁移时如何恢复旧版本。
- HTML 总结是给人回看的阅读产物，不能作为完整数据备份。

## 常见问题应如何排查

| 现象 | 正式说明必须提供的排查路径 |
|---|---|
| 网页打不开 | 产品服务是否启动、实际地址、端口冲突处理 |
| 可以读书但 AI 不回复 | AI 服务连接、认证、所选模型及请求失败信息 |
| 找不到外文原著 | 展示检索状态，允许继续中文解析或补充文件，不伪造匹配结果 |
| 重启后无法恢复讨论 | 产品数据目录和后端会话目录是否一致，定位失效原因并保留已有记录 |
| 深层分支不好找 | 路径导航、折叠展开及返回直接父讨论的方法 |
