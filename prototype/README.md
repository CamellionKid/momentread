# MomentRead 交互设计原型

沿用已选深色阅读界面，演示书架、阅读与多级概念分支、整理返回、来源核对和 HTML 小结。**不接真实 AI、不解析 EPUB、不持久化阅读数据；刷新重置。** 导入仅使用文件名，正文仍为演示文本。

## 启动

本次验证：macOS、Node 22.23.0（见 `.nvmrc`）、npm，Codex 内置 Chromium。命令从本目录运行：

```sh
nvm use
npm ci
npm run dev -- --host 127.0.0.1 --port 4173 --strictPort
```

打开 [阅读工作台](http://127.0.0.1:4173/)、[书架](http://127.0.0.1:4173/?screen=library) 或 [今日小结](http://127.0.0.1:4173/?screen=summary)。端口占用时改为另一个端口，并使用终端输出地址。Ctrl+C 停止服务。无需配置 API Key 或 CLI。

## 建议体验顺序

1. 默认打开「段落解析 → 先验 → 判断」。点击图上的「先天」与「判断」，观察独立草稿。
2. 在正文选中文字，点「解析一下」；在解释中选中概念，点「展开概念」。也可使用解释尾部的同名按钮。
3. 从一个概念继续创建子概念；使用路径或图节点来回切换。
4. 点击「整理并返回」，编辑后确认，只返回直接父讨论。
5. 右上角设置可模拟断开、原著候选及下一次保存失败。重试时编辑内容保留。
6. 打开今日小结，导出 HTML；下载文件能独立打开，但不是完整数据备份。

书架搜索、文件选择、目录标题切换、字号与进度控件可操作。目录不切换真实正文，进度不是 EPUB CFI；书内概念是讨论列表，尚无真实义项存储；小结计数是当前演示会话累计值，尚无每日归档和完整版本历史。

## 验证与结构

```sh
npm run build
npm run test:sites
```

`src/` 为交互原型；`evidence/` 为合成内容的浏览器验收截图和导出样本；[design-qa.md](design-qa.md) 记录测试范围与限制；[UI／UX 说明](../docs/design/UI-UX.md) 为设计交接。

构建输出到 `dist/`，依赖与产物不提交 Git。模板附带的 worker、构建脚本与 Sites 测试仅保留兼容能力，尚未发布到任何公网服务。生产后端架构以 [ARCHITECTURE.md](../docs/ARCHITECTURE.md) 为准，本原型不替代 CLI 技术验证。
