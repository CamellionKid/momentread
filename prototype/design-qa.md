## 五项视觉表面

| 表面 | 结论 |
|---|---|
| 字体 | 中文衬线保持已选风格，正文和控件层级明确。生成图无可靠字体元数据；macOS系统回退有少量字宽和抗锯齿差异，不声称精确字体匹配。 |
| 间距 | 三栏比例、顶栏和整理按钮位置接近来源。修复累计段距后，主体内容没有遮挡；高亮块约十余像素差异归为P3字体微调。树按真实数据布局，节距与静态图不同。 |
| 色彩 | 黑灰背景、灰白文字和细边界统一；只有活动节点使用蓝圈，键盘焦点为白框，无多色分支或闪烁。 |
| 图像／图标 | 主界面没有装饰位图；使用真实Phosphor图标组件，SVG线路是节点数据可视化。没有以截图替代UI或仿制封面。辅助图原样独立保存。 |
| 文案 | 正文、回复和文件选择明确为演示；候选始终待核，确认与失败有区分。讨论数量不冒充掌握率；单段手写小结正确显示。 |

首次视口未稳定的截图不作为证据，移到被忽略的项目`tmp/`。浏览器标签失效后重新连接，没有将工具错误归为产品错误。

## 浏览器交互验收

本轮及同一设计任务前序均使用合成数据：

| 场景 | 实际结果 |
|---|---|
| 正文真实鼠标选区 | 选中文字后「解析一下」创建新根；普通追问追加在原节点。 |
| 兄弟隔离 | 判断输入草稿→先天空草稿→返回判断恢复原草稿。 |
| 递归展开 | 判断→普遍性→必然性；五级路径可访问，见`deep-branch-mobile.png`。 |
| 逐层回馈 | 必然性确认只回普遍性；普遍性确认只回判断。 |
| 保存失败与重试 | 编辑内容保留，重试成功，见`summary-save-error.png`。 |
| 子小结修订 | 已有小结的直接父讨论显示待合并更新，不自动改写父结论。 |
| 原著候选 | 未选择时按钮禁用；选择德语候选后可保留，仍为待核，见`original-candidates.png`。 |
| 折叠 | 根下收起其他分支，图按钮8→6；展开全部恢复8。 |
| 键盘 | 图节点Tab可达；弹窗关闭按钮Shift+Tab到确认，Tab回关闭；Escape关闭并恢复整理按钮焦点。 |
| 字号 | 键盘右箭头使24px→25px；不是EPUB CFI定位测试。 |
| 连接断开 | 发送显示连接提示且保留草稿，正文仍可阅读。 |
| 书架／导入 | 搜索无结果与清空恢复；空导入提示；合成文件名导入、切回原书恢复工作区。没有将文件名测试当EPUB解析验证。 |
| HTML导出 | 点击下载，读回本任务文件并复制为`evidence/exported-summary.html`；浏览器打开副本显示书名、12%位置及手写小结。见`exported-summary-browser.png`。无外部资源依赖，未模拟断网。 |
| 控制台 | 操作后读取error／warn返回空列表；最终重开预览再次为空。 |

## 响应式证据

- 1487×1058：`reader-desktop.png`、`reader-hover.png`；页面无水平溢出。
- 1280×720：`reader-compact-desktop.png`；正文和讨论独立滚动，输入与整理按钮可见，页面宽1280。
- 390×844：`reader-mobile.png`、`discussion-mobile.png`、`deep-branch-mobile.png`、`summary-mobile.png`。正文／讨论切换、五级路径、输入及确认可用，页面宽390。
- 书架／小结：`library-desktop.png`、`daily-summary-desktop.png`、`library-mobile.png`、`daily-summary-mobile.png`。长页面full-page截图高度可超过视口，未缩放；移动普通页面宽375，另15px为纵向滚动条，无横向页面溢出。
