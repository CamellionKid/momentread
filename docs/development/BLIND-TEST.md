## 主链核对

- 真实 EPUB 复制导入后可阅读，目录、字号、同章节选段和阅读位置可用。
- 根讨论支持真实 Claude Code 输出；同一根回答可建立两个兄弟概念，兄弟下可继续建立两层子概念，草稿互不覆盖。
- 深层小结可编辑确认，并只返回直接父级；随后可逐层返回根讨论。
- 服务实际停止并以同一数据目录重启后，书籍、约 7% 阅读位置、活动节点、完整讨论树、草稿和已确认小结均可找回。
- 今日总结连续点击只接受一个运行；最终 Markdown 以标题、列表和加粗显示。
- HTML 在服务停止且测试浏览器断网时由 `file://` 打开；ZIP 在新的空数据目录恢复后找回书籍、位置、树、草稿和小结。
- matching 的一次允许覆盖该运行内后续 WebSearch／WebFetch，同轮不重复询问；其他运行仍需重新决定。

## 缺陷复测结论

语言修复同时进入学习上下文和 Claude CLI 系统提示。开发者使用三个独立真实 discussion 会话执行可重复的 `language` 探针，三份合成回答均超过 20 字且不含拉丁字母；新的无历史测试者再以真实 EPUB 检查三份回答，结果一致。该检查能发现明显的中外文粘连，不对哲学解释的正确性作自动评分。

Markdown 分支选区现在保存两个值：原始 Markdown 的 `exact` 继续用于消息偏移与来源校验，渲染后的 `displayText` 用于确认界面、分支引用、提示词和概念档案。旧记录没有 `displayText` 时回退到 `exact`。新的盲测者从加粗节点内部跨到普通文本完成拖选，三处 UI 读回和分支真实运行均通过。

## 测试环境偏差

- 完整主链第一次指定文件系统 profile 时，测试工具报告同机浏览器 daemon 已存在，因此改用新的隔离 Chrome 任务会话。离线 HTML 与恢复测试使用的新 profile 没有该警告。该偏差不影响数据目录、端口和任务上下文隔离，但不能宣称完整主链证明了全新物理浏览器配置目录。
- 两次定向选区测试的第一次坐标拖选都落在目标旁的普通文字。测试者在确认界面取消，没有写入产品数据，随后重新拖选后再作正式判断。可见坐标误差不计作产品通过证据。
- 一次中间语言盲测因测试 Agent 自身额度中断，只保留已经观察到的失败结果；没有用该轮证明后续功能。

## 尚未放行的能力

自动原著发现仍未通过真实成功用例。Claude Code WebSearch 完成权限和工具往返，但当前 provider 返回零条明确来源链接；固定 URL WebFetch 和独立正文取回成功不能替代候选发现。产品在此情况下明确显示“尚未核对”，继续中文解析，并允许用户补充原著文件；不得把模型回译或空结果当作原文。

临时原始报告和截图在测试结束时保存于各测试者的 `/tmp` evidence 目录，可能随系统清理而消失。仓库只保留本份去除私人正文和完整模型输出的验收摘要。
