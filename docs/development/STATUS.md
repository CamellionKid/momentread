## 放行判定

- [PRD A01–A21](../PRD.md) 原要求保留，不因未实现或验证失败而修改成通过。
- 来源取回成功不等于搜索成功，模型运行完成不等于工具成功。
- HTML 要在服务关闭、该测试浏览器断网后打开；ZIP 要在空数据目录恢复。
- README 命令必须在独立目录真实执行；盲测不读取源码或开发操作脚本。
- 独立测试发现的缺陷必须由开发者修复，再以原断言复验，详见 [SYSTEM-TESTS.md](SYSTEM-TESTS.md)。
