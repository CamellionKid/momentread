# MomentRead UI／UX v1

设计日期：2026-09-10。基于已确认的[阅读视觉](selected-prototype.png)，实现为[可点击原型](../../prototype/README.md)。这是后续生产开发的设计交付，不表示真实 EPUB、CLI、原著检索或持久化已经接入。

## 1. 信息架构与阅读路径

书架 → 打开书籍 → 阅读正文 → 选段「解析一下」→ 在解释里「展开概念」→ 继续追问或再展开 →「整理并返回」→ 编辑小结 → 确认 → 直接父讨论。今日小结从工作台顶栏进入，书内概念从解释尾部进入。

一个节点承载整场多轮讨论。普通发送不新增节点；主动解析新选段建立根节点，主动展开概念建立当前节点的子节点。同一个词可在不同来源下建立不同讨论，不按名称自动合并。

| 界面 | 主要内容与操作 | 返回规则 |
|---|---|---|
| 书架 | 文字书目、搜索、导入、继续阅读、最近活动讨论 | 同一页面会话内恢复书籍工作区 |
| 阅读工作台 | 正文、当前讨论、窄栏线路图；目录、字号、进度 | 讨论切换不重置正文；来源入口可主动定位选段 |
| 整理预览 | 可编辑的小结、来源路径、待核状态、保存失败 | 确认后才返回直接父讨论；取消留在本讨论 |
| 原文与来源 | 中文选段、待核／无结果／多个候选、补充原著 | 保留候选不等于原文已核实 |
| 书内概念 | 当前书籍的概念及来源路径、确认状态 | 点击恢复对应讨论 |
| 今日小结 | 书名、进度、讨论数量、确认小结、待续问题 | 回到阅读，或导出独立 HTML |

## 2. 视觉规则

- 阅读优先：桌面三栏约 55.2%／29.2%／15.6%，51px 顶栏；正文、讨论、线路图独立滚动。
- 背景 `#191919`，讨论面板 `#202020`，分隔线 `#383838`，正文 `#e6e5e1`，辅助文字 `#a8a8a4`。蓝色 `#27bafb` 仅表示当前图节点。
- 中文正文与讨论标题使用衬线字体：`Noto Serif SC → Songti SC → STSong → Georgia → serif`；控件使用系统无衬线。字体不随原型打包，macOS 本次使用系统回退；其他平台需另行核验。
- 基准正文 24px、约 1.6 行高；主标题约 49px，讨论标题 36px。较矮桌面适当压缩字号和间距，正文保留滚动。
- 主要按钮为浅灰底深色字，次要操作采用描边或文字；控件圆角 9px。使用 Phosphor 的真实图标组件。
- 图节点常态仅黑白灰点与连线；当前节点有静态蓝圈。文字只在 hover／focus 出现；键盘另保留白色焦点框，避免用蓝色表达多个状态。

## 3. 关键交互与状态

### 讨论与线路图

线路图保留多个根解析、兄弟概念与递归子概念；节点 42×42px 命中区域。当前祖先路径保持展开，其余分支通过「讨论操作」收起／全部展开。图宽随深度增长，窄栏可横向浏览；进入讨论、切换节点与调整视口时自动显露当前节点。

路径导航可横向滚动，并自动显露末端当前节点。生产 PRD 中的祖先省略菜单仍是后续实现要求；本原型以完整可滚动路径验证深层导航，不将它误报为省略菜单已实现。

每个讨论独立保留输入草稿、消息、滚动位置与小结。切换兄弟讨论不复制草稿；从图上离开不等于完成或回馈。

### 整理并返回

生成中 → 可编辑预览 → 保存中 → 成功返回／失败留在预览。空小结不能确认；保存中防止重复点击；失败保留编辑文字，重试可成功。根节点使用「整理这段」，确认后留在根节点。

确认的小结更新直接父节点的回馈记录，按子节点去重。子小结修订后，已有小结的父节点显示「待合并更新」，父节点重新整理时才合并。原型保留版本号与最新内容，**尚未实现可追溯的完整版本历史**。

### 来源与概念

默认「原文待核」。多个候选必须先选择才能保留，但仍显示待核；找不到原著也可以继续阅读。原型没有外文原著引句，不将模拟解释伪装成作者原文。补充文件仅演示选择流程，不读取正文。

书内概念按讨论来源列出，不自动把同名术语钉死为唯一解释。真正的义项结构、原文证据和跨段落调用留给真实学习闭环开发。

### 小结与导出

仅已确认的小结进入成果列表；单段手写小结也完整显示。统计是演示工作区累计数量，不是按真实日期过滤的学习统计；不计算掌握率。待续问题与建议是演示文案。导出生成内嵌样式的 HTML，转义内容中的 HTML 字符，包含当前书名、进度、确认小结和待核提示；没有外部脚本或资源依赖，不作为学习数据备份。

## 4. 尺寸、键盘与异常

| 范围／状态 | 处理 |
|---|---|
| ≥1000px | 三栏；1280×720 与 1487×1058 已检查 |
| 650–999px | 正文／讨论切换，讨论旁保留 150px 线路栏 |
| ≤650px | 单面板切换，讨论旁保留 96px 线路栏；节点不缩小；输入与整理按钮纵向排列 |
| 390×844 | 正文、讨论、五级路径、弹窗、书架与小结已检查；长页面纵向滚动 |
| 键盘 | 原生按钮、表单标签、图节点可聚焦；弹窗 Tab 循环、Escape 关闭、退出恢复触发点 |
| 中文输入 | Enter 发送、Shift+Enter 换行；输入法 composition 时不发送 |
| AI 断开 | 正文可用，发送时保留草稿并提示；演示开关可恢复 |
| 搜索／导入 | 搜索无结果提示；未选文件不能加入书架；文件名验证 `.epub` |
| 动效 | 不闪烁；支持 prefers-reduced-motion |

手机验证采用桌面浏览器视口模拟，未验证 iOS／Android 原生选区、软键盘和触摸手势；首版仍以桌面浏览器为主。

## 5. 实现交接

原型使用 React + JavaScript + Vite，状态仅驻留内存。生产架构仍按 React／TypeScript 前端、独立本地服务、Claude Code 首接的既定方向推进；不从原型的 state 对象反向冻结数据库或 API。

后续适配应分别替换阅读器、讨论运行、来源匹配和记录持久化，保留本设计的节点粒度与返回语义。真实接入必须补齐 EPUB 稳定定位、文件元数据、流式生成与取消、书籍隔离、版本历史、原著出处和重启恢复；对应 PRD 验收需重新执行。

视觉附件：`ui-v1/library-direction.png` 与 `ui-v1/summary-direction.png` 为 Creative Production 工作流中生成的辅助方向图，未经用户逐张确认；主视觉仍以已选阅读图为准。书架采用全局导航，避免辅助方向图把书名误放进全局标题；小结采用左对齐、实际确认内容与动态数量，保持各页面阅读节奏一致。

图标来源：[Phosphor React](https://github.com/phosphor-icons/react)。线路 SVG 用于真实节点数据的拓扑可视化，不是装饰插画。完整验收与截图见 [设计 QA](../../prototype/design-qa.md)。
